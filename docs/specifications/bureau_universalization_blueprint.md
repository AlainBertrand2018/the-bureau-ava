# The Universal Bureau: Global Contextualization Architecture
**Status:** DRAFT Specification  
**Target:** Feature "Universal Market Adapter" (The BCE)  
**Objective:** Enable global scalability by decoupling the engine from specific cultural contexts.

---

## 1. Executive Vision
Currently, **The Bureau** is a high-precision instrument calibrated for the **Mauritian** market. To scale into a global SaaS platform for Market Research agencies, the system must evolve from a "Local Tool" to a **"Universal Research Adapter."**

The goal is to allow a user in *any* location (e.g., Port Louis) to generate, audit, and validate research instruments for *any* target market (e.g., Tokyo, Berlin, Sao Paulo) with the same level of cultural nuance and "native" precision as a local expert.

This requires a new architectural layer: **The Bureau Context Engine (BCE)**.

---

## 2. Core Concept: The "Mission" Paradigm
We introduce a mandatory **Initialization Phase** before any tools can be used. This is the **"Cockpit Check"** metaphor.

*   **Current State:** Tools are "Always On" and default to Mauritian context.
*   **Future State:** Tools are "Offline" until a **Mission** is initialized. The Mission defines the "Physics" of the simulation (culture, language, demographics).

### The Metaphor
> "You don't just drive the car. You tell the car which country's road laws apply, and the car automatically adjusts the steering, signs, and warnings to match."

---

## 3. Architecture Components

### A. The Mission Object
A persistent state object that governs the user's entire session. It sits above the individual tools (Architect, Simulator, Auditor).

```json
{
  "mission_id": "MSN-2026-JP-TOKYO-001",
  "configurations": {
    "target_country": "Japan",
    "target_region": "Greater Tokyo Area",
    "target_language": "Japanese (Standard)",
    "market_segment": "Consumer Electronics"
  },
  "research_objective": "Validation of new smart-home assistant privacy features",
  "dossier_ref": "DOSSIER-JP-TOK-V1"
}
```

### B. The Context Dossier (The "Black Box")
Upon Mission Initialization, the system does NOT just save the country name. It triggers an **AI Research Agent** to generate a cached **Cultural Dossier**. This is the "Brain" of the context engine.

**Dossier Contents (Auto-Generated by Gemini):**
1.  **Cultural Axioms:**
    *   *Communication Style:* (e.g., High Context/Indirect vs. Low Context/Direct).
    *   *Hierarchy:* (e.g., Strict reverence for elders/titles vs. Egalitarian).
    *   *Taboos:* (e.g., Talking about money in public, questioning authority).
2.  **Linguistic Nuances:**
    *   *Honorifics:* (e.g., Requirement for Keigo in Japan, Voi/Lei in Italy).
    *   *Local Idioms:* Key phrases that signal "Insider" status.
3.  **Demographic Canvas:**
    *   *Population Structure:* (e.g., Aging population, Youth bulge).
    *   *Persona Archetypes:* 5-7 statistically representative profiles (e.g., "The Salaryman", "The OL - Office Lady").
4.  **Fieldwork Logistics:**
    *   *Preferred Channels:* (e.g., Line app in Thailand, WhatsApp in Brazil, SMS in US).
    *   *Interceptor Etiquette:* How to politely stop someone on the street.

### C. The Injection Middleware
A wrapper function that intercepts precisely *every* interaction between a Tool and the LLM.

`Wrapper(Tool_Prompt, Mission_Dossier) -> Final_Prompt`

**Example Workflow:**
1.  **User Input:** "Draft a question asking if they like the product."
2.  **Middleware Interception:**
    *   *Detects Mission:* Japan.
    *   *Reads Dossier:* "Japanese consumers rarely say 'No' directly. They use 'It is difficult'."
3.  **Modified Prompt to Gemini:** "Draft a question asking for product feedback. **CONSTRAINT:** Use Japanese 'Tatemae' (social face). Do not force a direct 'No'. Use scales that measure 'Hesitation' rather than 'Dislike'."
4.  **Result:** A native-feeling question that works in Tokyo.

## 4. User Experience (UX) Flow

### Phase 1: Mission Control (Initialization)
Before seeing the "Architect" grid, the user enters the **Mission Control** screen.
1.  **Select Target:** User chooses "Region" (World Map or Dropdown).
2.  **Define Scope:** User inputs "Objective" (e.g., "Testing a new Beverage").
3.  **Calibration (The 'Magic' Wait):** A loading screen where the AI "Warms up the engine."
    *   *Visual:* "Analyzing Tokyo Census Data..."
    *   *Visual:* "Calibrating Politeness Protocols..."
    *   *Visual:* "Generating Synthetic Population..."
4.  **Green Light:** The dashboard unlocks. The UI theme might subtly shift (e.g., timezone clock, local currency display) to reinforce context.

### Phase 2: Contextual Tool Usage
*   **Survey Architect:**
    *   Questions are drafted using the *Dossier's* linguistic rules.
    *   "Why?" justifications reference *local* cultural norms (e.g., "Relevance: Fits the Japanese value of 'Omotenashi'").
*   **Simulation Engine:**
    *   Instead of "Rajen", the simulator spawns "Kenji" and "Sakura" (from the Dossier).
    *   Feedback is culturally rigorous: "This question is too direct for a senior citizen in Osaka."

## 5. Technical Implementation Roadmap

### Step 1: Backend Data Structures
*   Create `MissionContext` class.
*   Create `CulturalDossier` class.
*   Implement `DossierGenerator` service (a specialized LLM chain to research a country).

### Step 2: The "Universalizer" Prompt
*   Refactor `simulation_engine.py`. Remove all hardcoded references to "Mauritius".
*   Replace with dynamic variables: `{dossier.country}`, `{dossier.cultural_rules}`, `{dossier.personas}`.

### Step 3: Frontend "Mission Control"
*   Build the specialized Onboarding Page (`/mission-control`).
*   Implement the "Calibration Animation" to show value (visualizing the AI learning the country).

### Step 4: Persona Dynamic Loader
*   Change `generate_personas` to stop using static lists.
*   Make it query the `Dossier` for the "Cast of Characters" relevant to this specific mission.

## 6. Business Value (The "SaaS Pitch")

By building this Universalization Layer, **The Bureau** transitions from a **Service** to a **Platform**.

| Feature | Value to Client (Agency) |
| :--- | :--- |
| **Instant Globalization** | A local team can execute global research without local partners. |
| **Cultural Safety** | AI prevents embarrassing or offensive mistakes in foreign markets. |
| **Operational Speed** | "Mission" setup takes 30 seconds; manual context research takes days. |
| **Consistency** | Every tool in the suite sings from the same cultural songsheet. |
